# Sistema Bancário API

Uma API REST bancária desenvolvida com Java e Spring Boot, focada em arquitetura limpa, segurança com JWT, boas práticas de mercado e simulação de operações bancárias reais, como autenticação, criação de contas, transferências, saques e depósitos.

---

## Features

- API RESTful completa  
- Arquitetura em camadas  
- Autenticação e autorização com JWT  
- Controle de acesso por rotas  
- Criação e gerenciamento de contas bancárias  
- Depósitos, saques e transferências  
- Histórico de transações  
- Tratamento global de exceções  
- Documentação com Swagger  

---

## Tech Stack

- Java 17  
- Spring Boot  
- Spring Web  
- Spring Data JPA  
- Spring Security  
- JWT  
- Hibernate  
- PostgreSQL / MySQL  
- Maven  
- Lombok  
- Swagger / OpenAPI  

---

## Architecture
Controller → DTO → Service → Entity → Repository → Database
